Important setup notes

  • QR tags: QR codes encode the FINDIT tag ID and can be printed. They do not reveal private owner information.
  • Shared school use: GitHub Pages is a static website. This version uses browser storage, so different browsers/devices do not share records.
  • For a real school launch: add a secure database and staff authentication (for example, Firebase or Supabase), plus a privacy policy and school approval.
  • Backup: export JSON regularly before clearing browser data.
